# Wine Quality Regression

Проект посвящён предсказанию качества вина (`quality`) по его характеристикам на датасете **Wine Quality UCI**. В работе объединены данные по красному и белому вину, проведён анализ данных и сравнены несколько подходов к задаче регрессии.

## Цель

Построить модель регрессии с **RMSE < 0.70** и исследовать, какие модели лучше описывают зависимость качества вина от его характеристик.

## Данные

Используются два набора данных:

- red wine;
- white wine.

После объединения был добавлен бинарный признак типа вина. Также были проверены пропуски и удалены полные дубликаты до разделения выборки на train и test.

Основные признаки:

- alcohol;
- volatile acidity;
- density;
- sulphates;
- residual sugar;
- chlorides;
- free / total sulfur dioxide;
- pH;
- fixed acidity;
- citric acid;
- wine type.

Целевая переменная — `quality`.

## Исследование

В ходе работы были протестированы:

- Baseline;
- Linear Regression;
- отдельные линейные модели для red и white wine;
- Ridge и Lasso;
- Spline Transformation + Ridge;
- RBF features + Ridge;
- Decision Tree;
- Random Forest;
- Gradient Boosting;
- LightGBM;
- CatBoost;
- XGBoost.

Для оценки использовались:

- **RMSE** — основная метрика
- **MAE**

Дополнительно исследовались feature importance и ошибки модели на различных значениях `quality`.

## Основные выводы

Простая линейная регрессия показывает, что физико-химические характеристики действительно связаны с качеством вина, однако линейной зависимости недостаточно для достижения высокого качества.

spline и RBF-преобразования улучшают результат, что указывает на наличие нелинейных зависимостей и взаимодействий между признаками.

Наилучшее качество показывают ансамбли деревьев и градиентный бустинг. Это связано с тем, что такие модели способны автоматически учитывать нелинейности, пороговые эффекты и взаимодействия между несколькими признаками.

Среди наиболее значимых признаков обычно оказываются `alcohol`, `volatile_acidity`, `density` и `sulphates`.
