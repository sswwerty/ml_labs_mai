# Titanic Classification

Проект посвящён предсказанию выживаемости пассажиров Титаника (`Survived`) по их характеристикам на датасете **Titanic Dataset**. В работе проведён разведочный анализ данных, исследованы зависимости между признаками и сравнены различные алгоритмы бинарной классификации.

## Цель

Построить модель классификации с **F1-score > 0.70** и исследовать, какие алгоритмы лучше предсказывают вероятность выживания пассажиров.

## Данные

Используется датасет **Titanic Dataset**:

https://www.kaggle.com/datasets/yasserh/titanic-dataset

Основные признаки:

- `Pclass` — класс пассажира;
- `Sex` — пол;
- `Age` — возраст;
- `SibSp` — количество братьев, сестёр и супругов на борту;
- `Parch` — количество родителей и детей;
- `Fare` — стоимость билета;
- `Embarked` — порт посадки;
- `Title` — обращение, извлечённое из имени пассажира (`Mr`, `Mrs`, `Miss`, `Master` и другие).

Целевая переменная — `Survived`:

- `0` — пассажир не выжил;
- `1` — пассажир выжил.

В ходе подготовки данных исследованы пропущенные значения, категориальные признаки и распределение классов. Для обработки категориальных переменных использовался One-Hot Encoding, для числовых признаков — масштабирование.

Дополнительно из имени пассажира извлечён признак `Title`. Редкие обращения объединены в отдельную категорию.

## Исследование

В ходе работы были протестированы:

- Dummy Classifier (baseline);
- Logistic Regression;
- Decision Tree;
- Random Forest;
- CatBoost;
- XGBoost;
- LightGBM;
- Support Vector Machine (SVM);
- K-Nearest Neighbors (KNN).

Для оценки использовались:

- **F1-score** — основная метрика;
- **Accuracy**;
- **Precision**;
- **Recall**.

Для моделей проводились подбор гиперпараметров с помощью `GridSearchCV` и оценка на кросс-валидации. Дополнительно исследовались матрицы ошибок (Confusion Matrix), переобучение моделей и важность признаков.

Особое внимание уделено связи нового признака `Title` с полом, возрастом, классом пассажира и выживаемостью.

## Основные выводы

Разведочный анализ показал, что выживаемость пассажиров связана с полом, классом обслуживания, возрастом и другими характеристиками.

Извлечённый из имени признак `Title` также связан с выживаемостью, однако частично дублирует информацию о поле и возрасте пассажира. В частности, между `Title_Mr` и `Sex_male` наблюдается сильная положительная корреляция.

Простые алгоритмы классификации позволяют выявить основные закономерности, однако ансамблевые методы способны дополнительно учитывать нелинейные зависимости и взаимодействия признаков.

**Наилучшее качество среди исследованных моделей показал CatBoost.** Его преимущество может быть связано с эффективным моделированием сложных зависимостей между характеристиками пассажиров.

Анализ Feature Importance позволяет выделить наиболее значимые признаки, а исследование False Positive и False Negative — определить группы пассажиров, для которых предсказания оказываются наиболее сложными.

## Итог

Работа демонстрирует полный цикл решения задачи бинарной классификации: от анализа данных и создания дополнительных признаков до обучения, настройки и сравнения различных алгоритмов.

Сравнение моделей показало преимущество CatBoost на использованной схеме оценки. Исследование важности признаков и ошибок классификации позволило дополнительно проанализировать закономерности выживаемости пассажиров и ограничения построенной модели.
